## GPU时长和接力

新runner记录训练、评测、checkpoint和其他阶段的rank最大墙钟时间，并乘4报告GPU占用小时。外层接力程序另外记录完整作业启动至退出的占用时间，覆盖模型加载；这些是GPU预留时间，不是内核活跃时间。阶段时间是作业时间的组成部分，不能再与整段作业时间相加。

旧05/06/07的已完成训练组和成功DEV64时长已按组复算，见回执中的 `timing_snapshot`；这份快照不包括未记录的失败评测时长，也不是旧实验全部GPU消耗。main07实际退出后，接力回执会补启动至观察到退出的完整作业时间（5秒轮询误差上界）。

接力工具 `ops/handoff_alpha100_after_shared_cap.py` 在服务器独立运行，不依赖当前聊天一直保持。它绑定旧PID和进程启动标识、源码SHA、固定命令和输出目录；使用单进程锁及持久化一次启动claim。旧作业异常结束、校验失败或新作业失败均记录原因，不自动重试GPU训练。开始续训前仍需加载同一原生模型。
