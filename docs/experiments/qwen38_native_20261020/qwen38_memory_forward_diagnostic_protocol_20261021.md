## 编码替换敏感度G

另保留一条按原H_base写入的基准轨迹。在每个写入前状态Δ上，以相同帧、批形状和lane分别取得H_base与H_mem；两种writer计算使用完全相同的直接Δ与计数。

对写入行j，分别按事件β归一化得到加权目标v̄_j。块级指标为：

`G = ||v̄(H_mem, Δ) − v̄(H_base, Δ)||F / ||Δ在本帧所有读取行上的有效值||F`。

分母使用去重后的全部读取行，包含prefix，不能用写入行代替。直接状态保持不变，但编码变化引起的目标和门控变化都进入分子。H_mem结果在这条基准轨迹中只作比较，不写入。

- 分母L2小于`1e-8`的块标为不可评估，不替换成epsilon后报告虚假的比值。
- 行级指标使用该写入行的有效旧Δ作为分母；低于同一阈值的行过滤并报告比例。它是行输出敏感度，不称为行自环增益。
- 报告G的中位数、p99、最大值、大于1的比例，以及合格/过滤块数；另报告行级统计、门控变化、归一化H变化。
- `p99>1`只标注为预定保守风险信号。它不证明失稳；`p99<1`也不认证收缩。该信号不会自动启动训练。

## 双轨迹与重复运行对照

除上述base轨迹，运行按H_mem写入的参考轨迹、未扰动重复轨迹，以及两个扰动轨迹。所有轨迹使用同一个80M writer和相同证据；各轨迹每块都沿自己的当前状态重新编码。

第一次得到非零状态后，在已有状态行的values上注入一个固定随机方向。方向由CPU私有generator产生，seed为17并结合全局轨迹索引；不消费训练RNG。两种预定扰动幅度为参考状态L2范数的`1e-3`和`1e-2`。方向相同，仅尺度不同；counts、地址、lazy clock及其他状态保持一致。

每块记录：

- 实际FP32舍入后的初始扰动范数；后续两状态差的L2范数。
- 相对初始扰动的放大倍数，以及相对当前参考状态范数的误差。
- 未扰动重复轨迹的端到端误差。它沿自己的状态递推，包含局部数值差异及其后续放大，不能当作固定输入的逐步测量底噪，也不能直接从扰动轨迹误差中相减。
- 参考与扰动状态的范数、非有限值及完整轨迹长度。

输出比较按两状态行地址的并集对齐。FP32输入扰动可能被reader的BF16数值路径抹平，因此观测零差异不能解释成严格收缩。不同尺度结果必须同时报告，不择优选取。

## 执行与账本

每个就绪波次固定六个编码调用：base、在base状态上读取的H_mem、参考、未扰动重复、两个扰动轨迹。各rank使用统一的波次数、批大小和inactive padding。每次均在LM head之前获取H，CE目标访问为0。

编码调用独立保存并恢复Python、NumPy、Torch CPU/CUDA及Megatron tensor-parallel RNG。执行前后比较writer、reader冻结状态和源文件身份；所有临时记忆与sampler副本只属于本诊断。

单列实际与padding编码输入tokens、collective编码调用数、GPU占用时间。非有限状态或协议/身份错误立即停止，失败消费不退款，不自动重试。诊断期间optimizer更新数与backward调用数必须为0。
