## T⁰ 与带记忆编码的双轨迹

T⁰ 对照使用原主线的 trajectory-major H12 编码缓存。参考、独立重复、两个扰动轨迹共享每块同一 H12，只重算 writer 和 D1，不为四条 T⁰ 轨迹分别调用 reader。每个扰动在首个非零写入状态上注入，同一 CPU 私有随机方向、同一相对幅度；仅改变 values。

带记忆编码的四轨迹各自沿当前状态重新编码。重复轨迹从空状态独立运行，误差表示端到端分离，不能当作可直接相减的局部底噪。

每个就绪波次还有同批、同 lane 的 T⁰ 与在 H12 基准状态上读取的 H_mem，用于 G 与残差输入诊断。G 的直接状态来自 H12 基准轨迹；第一轮 G 的直接状态来自小批 T⁰ 基准轨迹，两轮分别报告。

## 功能影响与 CE 预算

只对6条多写入轨迹最后一个、从未写入记忆的查询块评分。四条件为 memory_ref、memory_eps01、base_ref、base_eps01，固定 frame/lane/batch/mask。CE 配额在 CPU 校验时由真实 label mask 精确计算，为四倍末尾查询目标数，硬上限12,288。每次 native CE 前持久预收费，失败不退款。无优化器、无反向传播，writer、源训练状态与各 rank RNG 保持不变。

报告每轨迹的配对 NLL 差、轨迹均值、token 加权均值和最大绝对差；对照用户关心的约0.005 nat效应尺度，避免只用有正有负的总体均值掩盖轨迹差异。

## 残差输入批次差异

在原始 H、逐 token RMSNorm 后 H 和 writer 实际特征三个空间，分空状态与非空状态记录：小批 T⁰−H12、小批 H_mem−小批 T⁰、小批 H_mem−H12 的范数、比值和方向关系。H_mem 读取 H12 base writer 形成的写入前状态，匹配零初始化残差组第0组的状态路径。

若批次差异构成实质混杂，残差差值输入改为同批 `x_mem−x_base_matched`。冻结的原 writer 与残差特征第一半仍使用 H12；残差输出层全零，保留第0步的原 base 事件与状态梯度。训练与 DEV64 使用同一选择，新增编码单列收费。
