# 带记忆编码训练的效果来源：2×2 分解（2026-10-21）

> 背景见 `research/memory_aware_writer_stability_20261021.md` §7；分叉训练与两次 DEV64 的过程见 `research/qwen38_memory_forward_diagnostic_report_20261021.md`。
> 本文只回答一个诊断问题：整体微调组（下称 delta writer）在 DEV64 上的指标变化，哪些随训练后的写入器参数保留，哪些来自评测时的证据编码方式，以及历史执行布局差异能否解释这些变化。
> **研究目标仍是训练真正的持续学习写入器：证据编码读取已有 Δ，再把新证据写入持续演化的 Δ。T⁰ 格只用于分离参数变化与编码作用，不作为退回 T⁰ 的部署结论。**
> 2×2 的结果是：统一 B1 后，两个终点权重仍表现出文档区分指标上升、整体续写收益下降的主要趋势；本次 DEV64 未检出评测时带记忆编码的校正后正收益。这里的"权重"是"怎么写"的策略参数，知识内容在各格中均由使用时前向写入 Δ。结果说明本次训练改变了写入行为，尚未证明持续学习能力提高，也未证明两种证据编码等效。

## 1. 背景

- **主线**：α=1 写入器，只读 T⁰ 编码，训到 100M（`native_main_training_08`）。
- **delta writer**：从主线 80M 分叉，重放主线 80→100M 完全相同的 835 组，只是编码换成"读写入前记忆"（带记忆编码），全部写入器参数继续训练，继承 AdamW 状态（`native_memory_full_01`）。
- **训练 loss**：和主线逐组配对，delta writer 全程略差：835 组平均 +0.00059，95% 区间 [+0.00041, +0.00070]。
- **DEV64**（delta writer 评两次取平均，对比主线 100M）：Δ_donor 升高 0.006–0.010，Δ_empty 下降 0.009–0.017。两次评测之间的差别，Δ_empty 最大约 0.0003，Δ_donor 最大约 0.0013，都不显著。

但这两次评测和主线之间同时变了三样东西：权重、评测时的编码方式、编码的批次布局（delta writer 每次编码 1 条，主线是每次 12 块，即 H12）。诊断报告 §3 已测到，同一份证据在空记忆时换批次布局，写入器特征就差约 7.6%。所以需要分解。

## 2. 设计

四格统一用"每次编码 1 条"的批次布局，完整 DEV64 协议：64 个事件家族，0/1/4/8/16 篇干扰，带方向置换对照。

| | 只读 T⁰ 编码 | 带记忆编码 |
|---|---|---|
| 主线权重（100M） | A：新跑 | B：新跑 |
| delta writer 权重（100M） | C：新跑 | D：已有，两次评测取平均 |

另外拿主线原来的 H12 结果（A_H12）和 A 作历史执行布局对照。该对照还涉及 cache 顺序、RNG 执行和 writer 源码版本差异，不能视为只改变 batch 的纯因果实验。

**正式统计**：采用预先固定的 100,000 次家族配对 bootstrap，种子 20261021，对 6 个对比 × 5 个距离 × 2 个主指标共 60 项作 Bonferroni 校正，使用 99.9166667% 百分位区间。D 的两次执行先在每个家族内平均，独立统计单位仍为 64 个家族。只有一个训练种子，区间不包含训练过程本身的随机性。

§3 的点估计已与正式结果核对。§4 保留早期 4,000 次、种子 20261019 的逐项 95% 区间作为描述性辅表；这些未校正区间不用于最终显著性判断。正式校正结果列在 §4 末尾。

## 5. 结论

1. **统一 B1 后，终点权重差异仍在**：四格内部的权重比较保留了主要变化方向，因此历史对角线差异不能全部归因于 H12/B1 执行布局。H12 对照本身仍有跨版本混杂。
2. **T⁰ 格的意义是诊断写入策略是否改变**：固定 T⁰ 编码，只换权重（C−A），Δ_donor 的点估计增加 0.008～0.012，Δ_empty 减少 0.008～0.014；正式显著范围见 §4。固定带记忆编码的 D−B 也保留相同方向。这个对照支持两个终点参数对应不同写入行为，不能把它改写成应放弃带记忆编码的持续学习主线。
3. **本 DEV64 未检出评测时切换带记忆编码的校正后正收益**：这是一项条件性结果，不代表两种编码一样或带记忆编码没有价值。两组权重在零干扰时，带记忆编码的 Δ_empty 均显著下降。
4. **四格的 query 都读取相应 Δ**：本次变化的是写入前的证据编码是否读取已有 Δ，并非回答时使用或关闭记忆。DEV64 每个事件只有一篇相关报道，但该报道可以包含多块 D1 写入，后块仍可能使用前块记忆；它缺少的是专门的多篇相关证据长期累积与修订测试，不能称为完全没有记忆整合场景。

作为参数变化的诊断，C 相对 A 的描述性点估计是：
- 零干扰时 Δ_donor 从 0.023 到 0.032（约 +35%）；16 篇干扰后从 0.013 到 0.022（约 +70%），抗干扰保留率从 54% 提到 70%；
- 代价是自己记忆下的总收益 Δ_empty 低了约 0.011（约 16%）；训练 loss 也略差 0.0006。

这里的取舍应表述为**文档区分指标提高，但正确记忆条件下的续写收益下降**。例如零干扰时 A→C，self NLL 从 1.7741 升到 1.7849，donor NLL 从 1.7975 升到 1.8164；两者都变差，donor 恶化更多才扩大 Δ_donor。因此不能写成相对主线"对这篇文章更有用"，也不能据此证明记忆做了更好的语义分配。

**2×2 的价值是定位这次训练造成了怎样的写入行为变化，为带记忆的持续学习主线提供诊断依据。** 真正的目标仍是利用已有记忆理解并吸收后续证据，同时保持、整合或修订已写入的信息；这份 DEV64 结果尚未回答该目标是否实现。T⁰ 格的诊断价值不能替代这一目标。

## 6. 边界

- **只有一次训练**：没有第二个种子。五个距离的变化方向一致，是这两个固定终点的观察；不能靠主线检查点间的摆动范围排除训练随机性。
- **开发集上的条件性结论**：使用 DEV64，未用 FINAL；正式主比较已作 60 项校正。家族配对区间仍只反映这些固定终点在家族间的差异，不包含独立训练重复的不确定性。
- **机制未知**。两个猜测，都没有证据：
  - 后面块的 $H_{\text{mem}}$ 已经反映了记忆里的通用内容，写入器学会了不再重复写通用的东西；
  - 带记忆编码的不可复现引入了噪声，起了某种正则化作用。
- **只在 DEV64 这一种续写任务上完成该 2×2**。它包含多块状态积累和无关文章干扰，但不足以代表跨多篇相关证据的长期整合与修订。对持续学习能力的判断仍须来自既定长链任务，不能由 T⁰ 消融格代替。

## 7. 对后续的影响

1. **持续学习主线不变**：保留 delta writer 的带记忆证据编码与连续状态更新。T⁰ 只作为区分参数变化和编码作用的消融，不把"放回 T⁰"写成最终方案。
2. **2×2 已完成本轮诊断任务**：当前不追加 DEV，也不由本报告新增训练或长链实验安排。既定长链任务仍围绕真正的持续学习能力展开。
3. **论文里的写法**：报告固定 B1 下的参数对比、编码对比及其局限：训练后的写入行为发生了变化，文档区分指标上升与续写收益下降并存；本 DEV64 未检出评测时带记忆编码的校正后正收益。把这些作为持续学习主线的诊断结果，不包装成 T⁰ 部署路线，也不提前宣称持续学习能力已经提高。
