# M1 新事件 DEV64 完整曲线：执行范围追加登记

在[主检查点登记](m1_checkpoint_policy_20261020.md)后、任何指定检查点的新 DEV64 结果产生前，用户将执行范围扩展为 **0M、5M、10M……100M，共 21 个检查点**。本文件追加执行范围，保留前述主次选择，不覆盖原机器可读登记。

- 100M 为唯一主检查点，65M 保留为次要结果；其他检查点只用于描述新事件收益随训练量的变化。
- 0M 必须是实际 M1 初始化权重，逐点固定权重文件、SHA-256、步数和实际训练目标 token 数。
- 首批排队顺序为 100M、65M、0M、5M，其余按训练量递增；允许并行完成，不要求完成时间按该顺序。
- 从 4 个评测进程开始。仅根据显存、负载和事件对吞吐调整并发，最多 8 个；不根据分数决定保留哪些点。
- 所有点使用同一冻结 DEV64、同一评分和随机控制协议，不新增训练或改写原评测算法。
- 独立曲线登记文件引用此前主检查点登记的 SHA-256，并在执行前冻结全部 21 点清单。
- 不利用曲线重新挑选主检查点；FINAL 的 100M 唯一检查点、最多一次限制保持不变。本队列不执行 FINAL。
