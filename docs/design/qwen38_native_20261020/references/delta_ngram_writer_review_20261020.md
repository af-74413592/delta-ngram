# 写入器设计评议与原生 3.8 适配建议

2026-10-20｜审阅对象：`delta-ngram/src/delta_ngram/writer.py`（commit 7ab8b01，共 113 行）。附录另列两点，都和原生适配有关：α 消融结果的读法、D1 的数值稳定性。

## 0. 结论

- **骨架有依据，保留**。
- **具体超参是默认值，没有消融过**：目标网络隐层 128、右窗 4、单查询池化、只用最后一层隐状态。
- **原生 3.8 必须做的是接口适配**（维度、哈希头、初始尺度、读出路径），不需要重新设计。
- **要不要改结构，先看原生容量 oracle 的结果再决定**，不凭感觉改。

## 1. 当前实现（对照代码）

| 部件 | 实现 | 位置 |
|---|---|---|
| 输入 | 冻结、未打补丁的主干在证据块上的 LM-head 输入 H，已 detach | `events()` |
| 事件特征 | x_a = [H_p; mean(H_{p+1:p+4}); Pool(H); emb(阶数)]，维度 3×1024+32 | L46、L101 |
| 目标 | Linear(3104→128) → SiLU → Linear(128→1024) | L47 |
| 门控 | 输入为 x_a、旧值 Δ、v−Δ、log(1+c)；Linear(→128) → SiLU → Linear(→1) → sigmoid | L49、L108–112 |
| 池化 | Linear(1024→1) 打分后 softmax，零初始化（初始等于均值池化） | L44、L53 |
| 初始化 | 目标末层 std 1e-3；门控偏置 logit(0.05) | L55–58 |

## 2. 有依据、建议保留的部分

1. **只读冻结主干自己的隐状态**（不带记忆，已 detach）。写入器的输入与记忆无关，所以训练和使用一致，也不存在自激回路。
2. **门控能看到旧值、残差和写入次数**。写入步长由状态决定，对应 gated delta 的思路。"行已兼容时少写"能否被学出来，靠的就是这一点。
3. **用右侧上下文**。一行在位置 p 被读出，是为了预测 p 之后的词，所以写入内容需要参考后文。
4. **初始化**。目标小、门控小但不为零，第一步就有梯度。第 0 步评测时 self≈empty（Δ_empty = −0.0002），说明初始状态几乎不扰动主干。
5. **接口约束**。写入器只能看已到达的证据块，问题、答案和审计标签都进不来。

## 3. 未经消融的选择

| 选择 | 当前值 | 风险 |
|---|---|---|
| 目标网络隐层 | 128 | 末层是 128→1024 的线性映射，所有写入目标乃至 Δ 都被限制在一个固定的约 128 维子空间里。这是硬上限，可能限制原样复述 |
| 右窗 | 4 | 取值没有依据；更长的右窗可能更有利于写入"后面会出现什么" |
| 全文摘要 | 单查询注意力池化 | 每块只有一个摘要向量，块内所有事件共用 |
| 特征层 | 只用最后一层 | 没有直接提供后续 token 的身份（token embedding）。最后一层主要编码"对下一个词的预测"，当前词的身份保留得不完整。P1 诊断出的"擅长大意、弱于原样复述"可能与此有关 |

审稿人几乎一定会问"为什么是 4、为什么是 128"，至少要在附录里给出交代（见第 6 节）。

## 4. 原生 3.8 必须做的接口适配

1. **拆开输入维和行宽**。当前代码写死了 `hidden.shape[-1] == width`（L68），池化和特征拼接也都按 `width` 构造（L44、L46）。3.8 的隐状态是 2560 维，表行宽是 160。需要新增 `input_dim` 参数：特征维改为 3×input_dim + 嵌入维，目标头输出行宽。
2. **改为按（阶数，哈希头）做嵌入**。原生表每阶有多个哈希头，每个（位置，阶，头）都是一个写入事件，`head_embedding` 要改成按（阶，头）索引。
3. **目标网络隐层不低于行宽**。行宽是 160 时，把隐层设到 ≥160（例如 256），第 3 节说的子空间上限就消失了，代价可以忽略。
4. **初始尺度按 T⁰ 来定**。原生表 T⁰ 本身已有内容，绝对的 std 1e-3 没有意义。应按 T⁰ 每行（或每头）的 RMS 设定目标末层的初始尺度，并核对原生读出里的归一化和门控会把 Δ 实际放大多少。
5. **读出走原生路径**。T⁰+Δ 经原生读出注入原生层，不再沿用外挂表"在第 1 层加 ΣΔ/√2"的做法。写入器必须对着部署时的读出来训练（P2 的教训：在 Base 上训练、搬到后训练模型上，收益只剩约 1/5）。
6. **明确 H 取的是哪个张量**。3.8 有 hyper-connection（hc_count 4，残差宽 10240）。要写清"LM-head 输入"指的是 final norm 之后合并成的 2560 维末层，还是别的张量，并登记进 config。
7. **保持 D1 的块内平均**（见附录 B）。同一物理行在一块里被多个头或多个位置命中时，仍按 1/n_j 取平均，不能改成求和。

## 5. 先测再改：原生容量 oracle

计划里已经有这一步，建议把它作为写入器结构决策的依据：

1. 对每篇开发文档，在 3.8 上**直接用梯度优化 Δ**：只优化该文档实际触及的行，读出路径与部署时一致。这样得到"原生表加读出最多能装下多少"的上限。
2. 在同一批文档上，把 oracle 与写入器小规模试训（≤2M）的 Δ_empty、Δ_donor 放在一起比：
   - **oracle 本身收益就小**：瓶颈在表或读出，改写入器没用。
   - **写入器离 oracle 很远**：才值得改写入器结构（隐层、右窗、token embedding 特征）。
3. 判定阈值在看到结果之前登记。

| 组 | 改动 |
|---|---|
| 隐层 | 128 → 512 |
| 右窗 | 0 和 16（现状为 4） |
| 可选 | 把后续 token 的冻结输入 embedding 加入特征，并单独报告原样复述（按复现分桶） |

- **定位**：只作附录诊断，不改动 M1 主线。如果某组明显更好，在原生训练开始前决定是否采用，并登记依据。

## 附录 A：α 消融结果的读法（关系到原生 α=0.99 与 α=1 对照怎么报告）

**数据和方法**：用 `eval_step_000210.json` 与各个 `*_historical.json` 里的逐组 loss_sum 做配对，按来源分层重采样 1000 次。

| 版本 | 宏平均 Δ_donor | 宏平均 Δ_empty | 跨文章首块 Δ_donor（给定前 128 token） |
|---|---|---|---|
| D1（α=1） | 0.0677 | 0.1048 | 0.0907 |
| 固定 0.99 | 0.0673 | 0.1051 | 0.0912 |
| 固定 0.95 | 0.0712 | 0.1044 | 0.0891 |
| 可学习全局 | 0.0660 | 0.1048 | 0.0886 |
| 证据 α | 0.0816 | 0.1030 | 0.0486 |

证据 α 与 D1 的配对差（95% CI）：

| 指标 | 配对差 | 95% CI |
|---|---|---|
| Δ_donor | +0.0138 | [0.0124, 0.0152] |
| Δ_empty | −0.0017 | [−0.0023, −0.0012] |
| 跨文章首块 Δ_donor | −0.0421 | [−0.0519, −0.0325] |

1. **证据 α 塌缩了**。
   - **现象**：训练末段（第 180–210 步）α 的均值约 0.36，书籍上只有 0.22，半衰期不到一块，记忆实际上变成了"只记上一块"。
   - **原因**：Δ_donor 上升，是因为 donor 条件变差了（别人的记忆被忘掉），而不是 self 变好。Δ_empty 反而下降，跨文章收益减半。
   - **固定 0.95**：是同一现象的缩小版。
2. **Δ_donor 会被遗忘抬高**。凡是涉及遗忘或衰减的比较（包括原生 α=0.99 与 α=1 的对照），以及检查点选择，都必须同时报告 Δ_empty 和跨文章首块，不能只按 Δ_donor 排序。
3. **可学习全局 α 实际上没有动**。
   - **原因**：它和写入器共用 Adam 学习率 3e-4，86 步后只从 0.9900 变到 0.98985，报告里应注明它等同于固定 0.99。
   - **可作噪声参照**：它与固定 0.99 之间宏平均 Δ_donor 约 0.0013 的差，可以作为训练轨迹随机波动的参照。上面的组间置信区间没有包含这部分波动（只有一个种子）。

## 附录 B：D1 的数值稳定性（适配时不要破坏）

- **为什么不会爆**：D1 等价于 key 为 one-hot 的 DeltaNet。‖k‖²=1 自然成立，转移矩阵是对角阵 diag(1−w_j)，且 w_j∈[0,1]。前向连乘不会爆炸，新值始终是旧值与目标的凸组合。
- **关键在块内取平均**：同一行在一块内被命中 n 次时，如果求和，w=Σβ 可能远大于 1。比如 20×0.25=5，转移系数变成 −4，就会发散。平均在这里起到的作用，相当于 DeltaNet 里的 L2 normalize 加 sigmoid。
- **反向不严格受控**：沿状态的主项同样是 (1−w)，但门控会读取旧 Δ，Jacobian 多出 (1/n)Σ(v_a−Δ)∇β_aᵀ 这一项，严格来说不保证 ≤1。需要保留梯度裁剪，并持续记录裁剪前的梯度范数。
- **EFLA 形式不在本轮引入**：如果想要"命中次数越多改得越多"，可以用 EFLA 的形式 w=1−e^{−Σβ}，同样稳定。但这属于算子变更，按计划本轮不引入。
