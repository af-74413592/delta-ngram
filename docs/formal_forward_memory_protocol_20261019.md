日期：2026-10-19。本文给出本项目的定义与推导，不引用外部定理来替代实验结果。
定位：内部评测规范。论文正文只保留能力定义与评测条件两段；其余留作附录或内部审计。
论文核心仍是 Delta N-gram：在 N-gram 记忆行上以仅前向 D1 写入实现持久记忆，主干参数不变。
后续工作优先推进核心实验，不继续扩展形式化命题、更新算子或数据来源。
实际 D1 更新的代数与稳定性证明见 [D1 性质](formal_d1_properties_20261019.md)。

## 1. 所研究的能力

令冻结 reader 参数为 \(\phi\)，离线学习得到的 writer 参数为 \(\theta\)。
在线状态 \(S_t=(M_t,C_t)\) 包含可变稀疏记忆值与写入计数；它不是一份待优化的模型参数。
在时刻 \(t\) 已到达的证据块为 \(E_t\)，固定 tokenizer/hash 地址为 \(h\)。

\[
 S_t=U_\theta(S_{t-1},E_t;\phi,h),\qquad
 p_t(y\mid q)=R_\phi(y\mid q,M_t;h).
\]

**定义 1（本项目的完整在线能力）**：\(\phi,\theta,h\) 在整个在线轨迹上固定；
状态更新只调用 evidence encoder、writer 和指定更新算子的前向计算。
在线没有反向传播、梯度估计、优化器更新，也没有通过 query/答案损失调整状态。
计数更新、查表与函数式生成新状态都允许。每个独立事件从规定的空状态开始。

这一要求是计算过程的限制。只检查最终参数不变不足以证明它：先反向求梯度再恢复参数仍不符合定义。
实现证据包括评估函数的 `torch.no_grad()`、不构造优化器、writer 调用的数据边界、参数一致性检查及审计记录。
审计记录里的 `backward_calls=0` 本身是声明，需结合代码路径与测试检查，不能当独立运行时证明。

**离线训练**允许在训练事件上展开 \(U_\theta\) 并对 \(\theta\) 做 BPTT：

\[
 \min_\theta
 \sum_{e\in\mathcal D_{train}}\sum_{t\in T_e}
 -\log R_\phi(y_{e,t}\mid q_{e,t},M_{e,t-1}(\theta)).
\]

这写的是优化目标；\(\widehat\theta\) 定义为实际优化过程得到的参数，不声称 SGD 达到全局最小值。
reader 权重冻结，不等于无需经过 reader 计算图求 writer 梯度。
训练可以反向，不能由此把在线反向更新的 oracle 计入仅前向能力。
oracle 可单独诊断可优化上限，不进入 checkpoint 选择或完整能力的主结论。

## 2. 时间、可见性与块内双向特征

令 \(\mathcal F_t\) 是时刻 \(t\) 已公开且允许使用的证据、既定随机种子和固定参数生成的信息集合。
每个输入块必须是 \(\mathcal F_t\)-可测的；有新闻日期并不自动证明该版本正文在该日期已公开。
原文的发布时间、抓取/归档时间和后续修改时间必须分别登记，时间不明者不能冒充严格的先后证据。

writer 可看完整**已经到达**的证据块，包括块内右侧上下文和整块 attention pooling。
这不违反块级在线因果性，但不代表逐 token 到达时也无延迟。
本实现的延迟单位是至多 512 个新 token 的证据块；跨文章时地址和文本前缀重置。

**命题 1（前向轨迹的非预见性）**：若初始状态固定或 \(\mathcal F_0\)-可测，
每次更新的全部输入都属于 \(\mathcal F_t\)，且更新算法不读取未来文件、query 标签或梯度，
则 \(S_t\) 是 \(\mathcal F_t\)-可测的。

证明：初始时成立。若 \(S_{t-1}\) 可测，固定函数 \(U_\theta\) 对可测输入的组合仍可测；归纳即可。
随机实现需把当时可用的随机数也纳入 \(\mathcal F_t\)。
这是在数据访问假设成立时的过程结论；不能代替正文来源与代码数据流的审核。

## 3. 两种任务分别估计什么

### 3.1 离线事件流训练和历史 DEV

一个事件是严格按时间排序的完整文章序列 \((A_1,\ldots,A_k)\)。
第一篇所有块仅用于写入；后续文章的每一块先评分，再在需要服务后续块时写入。
最后一块不写入。文章边界不继承上一篇的 LM prefix 或 n-gram prefix，但保留事件记忆。
padding 不评分、不入证据池，也不触发写入。

后续文章的开头使用本地 BOS/EOS 作为预测条件，其全部真实 token 都可作为离线训练标签。
先读后写保证该块的记忆不含该块正文；评分时的 causal teacher forcing 只允许每个 token 的左侧文本作为语言条件。
后续块可以使用此前已读过的目标文章内容写成的记忆。因此这个任务包含**同篇持续适应**，不能单独估计跨文章迁移。
自动词面/URL 家族只是数据分组，不等于人工确认的同一现实事件或事实更新。

### 3.2 新事件原文续写主评估

较早完整原文为 \(E\)，较晚完整原文为 \(Q\)，预先固定的无关文章为 \(D_1,\ldots,D_{16}\)。
分别构建并冻结：

\[
 S^s_k=U(E,D_1,\ldots,D_k),\quad
 S^d_k=U(E_{donor},D_1,\ldots,D_k),\quad
 S^0=\varnothing,\qquad k\in\{0,1,4,8,16\}.
\]

这里 \(U(\cdot)\) 表示按文章和块顺序反复前向更新，不含任何训练。
donor 必须属于另一事件并在 query 前可用；干扰文章也需在 query 前已可用。
所有条件读同一份 \(Q\)，给定相同的前 128 token，并以相同本地滚动前缀评分之后的 token。
**整个 \(Q\) 都禁止传入 writer**，包括评分后，也包括用作局部前缀的文本。

这时每个 target token 的 NLL 为：

\[
 \ell^c_{i,k}=-\log R_\phi(q_i\mid q_{\max(0,b(i)-128):i},M^c_k),
\]

其中 \(b(i)\) 是评分块起点；输入还包含本块中 token \(i\) 左侧的真实 token。
teacher forcing 提供真实左侧上下文用于测量条件概率，不等于模型自主生成质量。
报告全续写 NLL，并另报第一个评分块，避免很长的已知左侧正文掩盖早期记忆作用。
QA 是补充诊断，不替代此项原文续写测量。

**命题 2（query 不进入记忆）**：若只在 \(E,D_{1:k}\) 上调用更新，且评分只读冻结状态，
那么给定证据、参数和随机性后，\(S^s_k\) 不依赖 \(Q\)。
证明：逐次更新的函数复合里没有 \(Q\) 这个变量。评分计算需要再次满足 reader 的 causal mask。
这比“同一块先读后写”更强，也是新事件续写评估与历史事件流训练的关键区别。

## 4. self、empty、donor 的可辨识性

对固定事件、固定评分 token 集合与固定权重，记三条件平均 NLL 为 \(L_s,L_0,L_d\)。定义：

\[
 \Delta_{empty}=L_0-L_s,\qquad
 \Delta_{donor}=L_d-L_s,\qquad
 B_{donor}=L_0-L_d.
\]

于是严格恒等式：\(\Delta_{empty}=\Delta_{donor}+B_{donor}\)。
`empty` 增益可以部分来自一般写入偏置；增加 donor 使这个成分可观察。
但 \(\Delta_{donor}>0\) 只说明 self 优于**所指定 donor 策略**。
它可能还涉及地址命中、题材相似度、长度、密度或门控统计，并不自动等于事实语义更新。

**反例（只有 empty 不足）**：writer 对所有输入写入相同有利偏置，reader 的目标 NLL 因此下降。
此时 \(\Delta_{empty}>0\)，但等结构 donor 得到相同状态，因此 \(\Delta_{donor}=0\)。

**条件性结论**：若 self/donor 的非内容因素精确匹配，且假设 writer/reader 在所研究零假设下对证据内容不敏感，
则两者状态/预测分布相同，从而期望 \(\Delta_{donor}=0\)。证明是把内容无关性代入相同计算图。
拒绝此零假设最多支持对本对照所改变因素的敏感性。若非内容因素未匹配，结论需要收窄。

当前历史 DEV 的普通文档 donor 匹配来源、块数与块大小；事件 donor 匹配来源、长度桶、不同家族和实际写入 token 数。
事件 donor 保留自己的文章边界，拆分可能带来更多真实 write 调用，因此**未实现完整结构精确匹配**。
新事件原文 donor 同样需逐条件报告正文长度、实际写入块数和记忆占用；其固定匹配规则不能按效果事后修改。
上述限制需随主结果披露。新事件评估在看结果前预登记 `self-perm` / `donor-perm`：
对整份 memory 使用共享的 width 维坐标置换，仅改变 read view 的方向；地址、计数、每行元素多重集与范数保持，原 memory 的后续写入轨迹不变。
范围为所有事件、所有距离、所有非空记忆行，固定 seeds 为 17、29、43；同 seed 的同一置换用于 self 与 donor。
算法为 `random.Random(seed).shuffle(list(range(width)))`，记录完整置换及其 SHA。
主方向结果在事件内先平均三个 seed，另报每 seed；不挑最好 seed，不把三个 seed 当作三个独立事件。
该控制检查记忆方向与冻结 reader 的对齐，仍不单独证明事实语义。

## 5. 保留性与可修订性不能混为一个分数

定义保留曲线 \(G(k)=\Delta_{donor}(k)\)，报告 \(k=0,1,4,8,16\)。
同时报告实际干扰 token、write 调用数、被触及物理行数与 query 命中；同样 4 篇文章的写入负荷可能差很多。
建议主报绝对差 \(G(k)-G(0)\)。比值 \(G(k)/G(0)\) 仅在分母明确远离零时作补充，负增益或近零时不用其宣传保留率。

修订任务需另行标注旧事实、修订证据及新旧答案。读到后续文章不保证文章实际上修正旧事实。
修订后的正确更新与对无关事件的保留是两个结果，不能用任一单项推出另一项。

**命题 3（不可区分状态的限制）**：对两个世界，若在线全部可观察输入、初始状态和随机性相同，
reader 的 query 也相同，但正确答案不同，则任何确定性系统至少在一个世界答错；
随机系统在两个等概率世界的精确答案成功率最多为 \(1/2\)。
证明：相同输入递推得到相同状态与输出分布。两个互斥答案的输出概率和至多为 1。
它说明无外部区分信息时无法同时保证所有修订与保留；不能反推本数据已经发生不可区分，也不能给当前模型错误率下界。

哈希碰撞本身不一定造成这样的不可区分：query 还有语言上下文，多行/多阶地址也可能区分。
必须把 reader 能访问的全部信息纳入假设，才能使用该命题。

## 6. 统计单位、选择与最终报告

1. 固定 tokenizer、reader revision、数据 SHA、时间规则、donor 映射、干扰序列与 target 集合后再评分。
2. 同一家族的多个窗口相关，配对 bootstrap 的单位是家族；不能把每个 token 当独立样本。
3. 五个语义来源按等权 macro 汇总。`news` 与 `news_event` 合并为一个来源；来源内部按冻结 DEV 的 target 数加权。
4. 每 5M 训练 target token 的 checkpoint 在同一冻结 DEV 上做 self/empty/donor。当前选择规则要求两种 macro 增益的家族 bootstrap 区间下界都大于零，再最大化 macro donor 增益，同值取最早。
5. 若无合格 checkpoint，报告无合格结果；不能降低门槛或使用 oracle 分数补位。
6. 这些 DEV 区间是选择工具，不是经过多次比较或选择后校正的显著性证明。最终结论在未参与选择的封存 FINAL 上检验。
7. 固定 donor 可能复用同一家族；条件于当前 donor 池的配对家族 bootstrap 不保证对全新 donor 总体的无条件覆盖率。应保留映射与复用统计，避免把启发式区间当普遍置信保证。
8. 当前原文 DEV 的 16 对是工程验证；正式跨事件结论的预定门槛仍为至少 64 个独立事件。64 是协议门槛，不是统计功效证明。

历史训练正文来自 2017，历史 DEV 来自 2018 的已审计时间段；较新的评估正文来自 2025/2026。
这定义了我们的训练/评估隔离，**不证明基础 reader 的预训练截止日期**，也不证明基础模型完全没见过某个新闻事实。
因此需同时保留 empty 基线与具体来源版本，并谨慎表述“新信息”。
